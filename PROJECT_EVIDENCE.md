# Project evidence guide

## Evidence classes

- **Professional reconstruction:** demonstrates methods used in a described role, rebuilt without employer data or code.
- **Independent simulation:** demonstrates a technical approach using synthetic assumptions; it is not presented as production experience.
- **Illustrative dashboard value:** a number used only to make a reconstructed screen coherent.
- **Verified resume outcome:** a result retained from the current resume and stated with the same qualification.

## Claims safe to discuss

- Rezo.ai calling analysis identified major drop-off after the first two questions.
- Recommended contact-window and question-sequence changes were associated with conversion moving from approximately 32% to 39%, above a 35% target.
- PhysicsWallah analytics supported more than 200,000 students annually.
- Question-level analytical views covered more than 20 million records and reduced a reported response time from approximately 13 seconds to 6 seconds.
- Scheduled SQL, Python and Airflow work reduced recurring manual effort and improved daily metric availability.

## Claims that must stay labelled as demonstrations

- BigQuery migration, cloud cost savings and production GCP deployment.
- Exact revenue, retention and utilization numbers shown in dashboard images.
- Exact Airflow runtime, task count, success rate and zero manual intervention.
- Any dashboard-screen value not supported by the current resume.
